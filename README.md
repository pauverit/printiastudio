# PRINTIA STUDIO

El programa de diseño y preimpresión de **PRINTIA HUB**, para los ordenadores de diseño del taller:
empiezas por lo que haces, lo ves en 3D (el vehículo, el roll-up, la valla, la fachada) y lo mandas al RIP,
unido a las órdenes del taller.

Aquí sólo están **las versiones para descargar**. No hay código fuente.

## Descargar

**[La última versión para Windows](https://github.com/pauverit/printiastudio/releases/latest/download/printiastudio-windows-x64.exe)**
(Windows 10 y 11, unos 130 MB). Se abre sin instalar.

- **Necesitas una cuenta de PRINTIA HUB.** Sin ella, el programa no hace nada.
- **Todavía no va firmado.** La primera vez, Windows avisa de que no conoce el programa: pulsa
  «Más información» y después «Ejecutar de todas formas».
- Cada versión trae su huella SHA-256 en sus notas, para comprobar que el fichero es el nuestro.
- Mac y Linux, cuando estén probados.
